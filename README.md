# Lastenheft- & Pflichtenheft-Editor – iPad-App

Installierbare Web-App zum Schreiben von Elektronik-Lastenheften und -Pflichtenheften
(Oberfläche im Stil von Microsoft Word, Vorlagen, Word- und PDF-Export).

## Installation auf dem iPad
1. Die Adresse dieser Seite (GitHub Pages) in **Safari** öffnen.
2. **Teilen → Zum Home-Bildschirm → Hinzufügen**.
3. Die App über das neue Symbol starten – sie läuft im Vollbild, auch ohne Internet.

## Datenschutz
Dieses Projekt enthält nur das Programm. **Alle Dokumente werden ausschließlich auf dem Gerät gespeichert**
(App-Speicher) und nie an einen Server übertragen. Austausch mit dem PC: Datei → Exportieren →
„Projektdatei sichern“ → „In Dateien sichern“ (z. B. iCloud Drive).

## Aktualisieren
Neue Programmversion in dieses Projekt hochladen und in `sw.js` die `VERSION` erhöhen.
Die App lädt die neue Version beim nächsten Start im Hintergrund und verwendet sie ab dem darauffolgenden Start.
